# 跟随英文输入高亮中文

本次需求：正在输入哪个英文词，就在中文原文中突出对应词组或句子。中英语序与词数不同，使用语义对应关系，不能用字符比例猜测。

## 行为

- 保持现有连续长卷、唯一输入框、大小写宽容和保存格式。
- 按英文目标及输入光标定位；输入、退格、移动光标与自动换段会更新中文高亮。
- 支持多词对应短语、中文语序反转和同一中文范围对应多个英文片段。
- 没有对应关系时显示准备提示，不显示伪造的精确高亮。
- 开始连续练习后，仅处理当前及接下来三段。滚动、打开软件和读取缓存不产生 AI 请求。
- 新段一次请求获取翻译和对应关系；已有译文只补对应关系，保持英文原样。
- 暂停、失败、切书后停止安排后续请求；已发出的有效结果可保存，不进行隐藏重试。

## 实现

模型返回英文与中文精确片段及中文出现序号；本机检查完整覆盖、边界、文本和大小，再换算为 UTF-16 范围。中文原文以安全文本节点和 mark 渲染，不拼接 HTML。

对应关系保存在数据目录的 alignment-cache 中，以原文、译文和版本绑定。缓存按段原子写入，不修改 Library v1 或重写大书库。编辑译文使旧对应关系失效。导出的旧书库格式不包含派生缓存，换电脑后按需补齐。

## 验证与交付

1. 校验、缓存、光标定位和请求失败的单元测试。
2. 隔离 Electron 测试：词组高亮、退格、选区、自动跨段、旧译文、重启、暂停、滚动、失败和请求范围。
3. 大书库性能回归；发行包白名单与启动检查。
4. 升级前正常退出并完整备份本机数据。整书翻译任务保持用户暂停状态。

AI 对应关系可能有语义误差；结构验证保证文本范围有效，不代表模型含义判断绝对正确。
