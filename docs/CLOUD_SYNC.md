# NovelType 账号与 X99 同步

本次范围由用户明确提出：将翻译后台放在 X99，建立管理员账号，另一台电脑登录后共享小说、翻译缓存、打字位置、API 配置和游戏进度。已认可 Arcade 视觉稿；此变更先实现后台及账号接入。

## 数据与权限

- X99 独立 Docker 服务、SQLite 数据库与持久化目录；不使用其他业务的数据卷。
- 账号、密码校验值、会话和用户数据隔离；无公开注册。管理员通过本机管理入口建立账号。
- API Key 在服务端加密存储，客户端只取得已配置状态。会话只在 Electron 主进程使用 Windows 安全存储；界面不取得密钥或 token。
- 原 `%APPDATA%/NovelType` 继续作为未登录书库。登录使用服务器与用户绑定的独立缓存；迁移前完整备份，不覆盖原书库。

## 同步约定

- 书籍元数据、每 128 段正文、打字进度、游戏记录、中英对应关系分别同步。日常只发送有变化的实体。
- 服务端以事务和长期 mutationId 去重保存，版本比较阻止旧电脑覆盖新版本。冲突保留两份，由用户选择。
- 离线先保存在本机和待同步队列；重新连接后只重送幂等同步请求。
- 登录与手动刷新在暂停练习后应用新数据，后台同步不会移动正在输入的光标。
- 翻译只有用户开始练习后由当前与后面最多三段触发；相同段落复用服务端缓存。API 请求失败或结果未知不自动重新付费请求；整书翻译继续暂停。

## 验证与发布

必须覆盖双设备同步、断网队列恢复、重复请求、进度冲突、跨账号隔离、服务器重启、凭证隐藏与已有桌面回归。真实密钥和私人小说不进入 Git、公开下载包或测试输出。

公网入口计划为 `https://noveltype.kinoraworks.com`。共享网关的 immutable 保护与实际切换需单独记录维护授权和验证，已存在 DNS 不等同部署完成。
