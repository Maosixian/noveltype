# NovelType · 逐页

把喜欢的中文故事变成英文打字练习。Windows 桌面软件，连续阅读、连续输入，不用一段段点「下一部分」。

## 下载与使用

在 [Releases](https://github.com/Maosixian/noveltype/releases) 下载 Windows x64 版本：

- **安装版**：`NovelType-Setup-版本号-x64.exe`，双击完成安装后，从桌面或开始菜单打开。
- **免安装 ZIP**：`NovelType-版本号-win-x64.zip`，完整解压后运行 `NovelType.exe`，不能只发送其中一个 EXE。
- **校验文件**：`SHA256SUMS.txt`，用于核对下载是否完整。

支持 Windows 10/11 x64。当前发行包未配置商业代码签名证书，Windows 或企业策略可能阻止安装/启动；请遵循系统提示与管理员策略，不要关闭安全保护。仓库中的构建成功记录不等于在所有电脑上通过了安装验收。

先练习内置原创双语示例，无需 Key。使用 AI 翻译时，在「翻译设置」填写自己的 API Key；智谱可填写 `glm-5.3` 等账号可用模型。每位使用者独立配置，软件不附带作者的密钥。详细步骤见 [使用说明](使用说明.md)。

## 已有功能

- 导入 TXT 或粘贴中文小说，保留原文并分成适合练习的小段。
- 支持智谱 GLM、DeepSeek、OpenAI 及兼容接口，译文可手动编辑。
- 上下连续滚动，打完自动进入下一段，输入焦点保留。
- **不区分大小写**；字母、标点和空格仍逐字检查。
- 当前段与下一小段按需翻译，暂停后停止安排新请求；滚动本身不调用 API。
- 本机保存书库、译文、草稿和进度；提供书库导出与恢复。
- 显示 WPM、准确率和时间，改错前的错误仍计入本次准确率。

## 数据与隐私

书库和进度保存在 `%APPDATA%/NovelType`，与程序目录分离。API Key 由 Windows 加密保存，书库备份不包含 Key。小说正文与译文在本机以明文保存，备份可能包含私人内容。

发行包只含程序和原创示例，不包含任何个人小说、Key 或练习进度。可以将官方安装包或 ZIP 原样分享给别人。不要分享自己的数据目录。AI 翻译会把当前及最多下一小段发给你选择的服务商，服务商可能计费；连接测试也会发送最小示例请求。

## 更新

后续源码、版本记录和安装包都在这个仓库维护。用户从 Releases 下载新版，在退出软件后更新；先导出书库备份。安装包升级保留数据目录，ZIP 版可直接解压到新文件夹。当前不提供后台静默自动更新。

维护者流程见 [发布说明](docs/RELEASING.md)。

## 本地开发

需要 Node.js 24 和 npm；桌面测试、Windows 打包在 Windows 上运行。

```powershell
npm ci
npm test
npm start
npm run test:desktop
npm run dist
npm run verify:release
node test/packaged-smoke.cjs
```

测试使用隔离书库与模拟 API，不需要真实 Key。打包检查使用全新临时数据目录，验证后清理。安装器和 ZIP 在 `dist/`，不提交到 Git。

## 范围

目前支持 TXT 和粘贴导入，暂不直接解析 EPUB/PDF/Word。AI 翻译可能错译人名、专有名词和情节，可以手动修订。极大书库和长期使用性能未完成专项压测。

源码尚未指定开源许可证（`UNLICENSED`）；公开仓库用于查看与维护，第三方依赖保留各自许可证。
